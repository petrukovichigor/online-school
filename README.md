# 📚 Название проекта: Учебное IT-приложение "Языковая Школа"

Проект представляет собой десктопное приложение для автоматизации процессов обучения в языковой школе. Реализовано разграничение прав доступа для двух ключевых ролей: **Студент** и **Преподаватель**. Данные надежно хранятся в реляционной СУБД PostgreSQL, а графический интерфейс спроектирован на основе прототипов из Figma.

---

## 🛠 Технологический стек проекта

*   **Язык разработки:** Python 3.10+
*   **СУБД:** PostgreSQL (Реляционная база данных)
*   **Администрирование БД:** DBeaver
*   **UI-фреймворк:** CustomTkinter / Flet (Современный графический интерфейс)
*   **Подключение к БД:** `psycopg` (Psycopg 3 — современный асинхронно-совместимый драйвер)
*   **Безопасность и криптография:** `bcrypt` / `hashlib` (Хеширование паролей на стороне Python)
*   **Конфигурация окружения:** `python-dotenv` (Безопасное хранение секретов в `.env`)
*   **Система контроля версий:** Git
*   **Упаковка приложения:** `PyInstaller` (Сборка в автономный `.exe` файл)
*   **Управление разработкой:** Google Документы

---

## 📈 Стадии реализации проекта

1.  **🟣 1 стадия:** Проектирование архитектуры БД, настройка связей, генерация ER-диаграммы в DBeaver и описание проекта. Наполнение таблиц тестовыми данными через CSV.
2.  **🟢 2 стадия:** Разработка Frontend части. Прототипирование окон в Figma и их перенос в код на Python (Окно авторизации, интерфейсы Студента и Преподавателя).
3.  **🔵 3 стадия:** Разработка Backend части. Безопасное подключение к PostgreSQL, написание SQL-запросов под каждую роль, интеграция бизнес-логики и безопасного хеширования паролей.
4.  **🟡 4 стадия:** Финальная сборка приложения с помощью PyInstaller, тестирование взаимодействия компонентов и подготовка проекта к защите.

## 🔒 Безопасность и архитектура данных

*   **Защита конфигурации:** Все параметры подключения к базе данных (`DB_HOST`, `DB_PASSWORD` и др.) вынесены в изолированные переменные окружения в файле `.env` и никогда не публикуются в открытый репозиторий.
*   **Хеширование паролей:** В приложении реализована концепция Zero-Knowledge по отношению к паролям. В СУБД PostgreSQL отправляются и хранятся только криптографически стойкие хэши данных, сгенерированные библиотекой `bcrypt` на стороне клиента. Чистые пароли перехватить невозможно.
*   **Целостность данных:** На уровне СУБД настроены строгие правила ограничений (Primary и Foreign Keys), а также каскадное удаление данных (`ON DELETE CASCADE`) для предотвращения появления "сиротских" записей в расписании и курсах при удалении связанных сущностей.

## 🚀 Инструкция по локальному развертыванию

### 1. Подготовка Базы Данных
1. Откройте **DBeaver** и подключитесь к вашему серверу PostgreSQL.
2. Создайте новую базу данных (например, `online_school_db`).
3. Откройте SQL-редактор, скопируйте туда содержимое файла `database/schema.sql` и выполните скрипт для создания таблиц.
4. Выполните импорт тестовых данных из файлов папки `database/mock_data/` в соответствующие таблицы.

### 2. Настройка Python-окружения
Склонируйте репозиторий и перейдите в корень проекта. Установите зависимости одной командой:
```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения
Создайте файл `.env` в корневом каталоге проекта и укажите ваши параметры подключения:
```env
DB_HOST=localhost
DB_PORT=5432
DB_NAME=online_school_db
DB_USER=your_postgres_user
DB_PASSWORD=your_postgres_password
```

### 4. Запуск приложения
Запустите главный модуль графического интерфейса:
```bash
python main.py
```
